For the task of segmentation, we propose two different neural network architectures:

  • PointNet based architecture, which is a novel type of convolutional neural network designed to consume point clouds.

    • Learns based only on point coordinates, by performing a series of convolutions.

    • In this implementation, PointNet makes use of 1-dimensional convolution. The output value of a layer with input size \( (B, C_{in} N) \) and output \((B, C_{out} N_{out})\) is:

      \(out(B_i, C_{out_j}) = bias(C_{out_j}) + \sum_{k=0}^{C_{in}-1}weight(C_{out_j}, k) * input(B_i,k)\), where

      • \(*\) is the cross-correlation operator,
      • \(B\) is batch size,
      • \(C\) denotes the number of channels,
      • \(N\) is the sequence length (in our case, the number of points).

  • Graph Convolutional Neural Network (GCN)

    • Designed to learn on point coordinates, edges and edge weights.

    • The network perform a series of graph convolutions, using GCNConv layers, with the following propagation rule:

      \( X^{(l+1)} = \hat{D}^{-1/2}\hat{A}\hat{D}^{-1/2}X^{(l)}W^{(l)} \), where

      • \(X^{(l)}\) - input for layer \((l)\)

      • \(\hat{A} = A + I\), where \(A\) is the adjacency matrix of the graph, and \(I\) is the identity matrix (i.e. \(\hat{A}\) is the adjacency matrix with added self-loops)

      • \(\hat{D}\) - diagonal node degree matrix for graph with self loops, measuring the degree of each node (i.e. \(\hat{D}_{ii} = \sum_{j}\hat{A}_{ij}\))
