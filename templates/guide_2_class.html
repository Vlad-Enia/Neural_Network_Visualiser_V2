Dataset

  • For the task of point cloud classification, we've chosen the ModelNet dataset. Collected by Princeton, the ModelNet projects aims to provide researchers with a comprehensive, clean collection of 3D CAD models for objects belonging to different classes that are frequently part of everyone's life such as beds, chairs, desks, bathtubs and more.

  • These are the class frequencies:

    Because we are dealing with an unbalanced dataset, samples of the same size will be extracted from each class, for both training and testing.

  • After processing the points is done, the next step is to compute the graphs. Each data sample will be used to construct one corresponding graph. Depending on the preference of the user, two different algorithms are provided: K-Nearest Neighbours (KNN) and Fix-Radius.

  • Using KNN, for each data point, we compute the first \(k\) nearest neighbours. In the below image (right), we set \(k = 6\). Therefore, the 6 points connected coloured with red edges are the nearest points, so we will consider them as node connections in our graph. The other nodes are too far, so they are excluded from the graph. Computing graphs using KNN is faster, but the disadvantage is that each data point will have the same number of neighbours.

  • Using Fix-Radius, for each data point, we consider all other nodes that are inside a circle (sphere in 3D space) with a fixed radius as the node's neighbours. In the left below image we only include the the node inside the blue sphere as graph connections. Compared to KNN, this method will give us different popularity within the graph, as nodes closer to the center will have more connections.
